**DESCRIPTION 
This project is a responsive Weather App developed as part of Internship Task 1 on API Integration using full-stack web development concepts. The main objective of this task is to create a web application that fetches and displays real-time data from a public API. In this project, I used HTML, CSS, and JavaScript to build a user-friendly interface that retrieves live weather information for any city entered by the user.

The application demonstrates how to integrate external APIs into a web application. An API (Application Programming Interface) allows two software systems to communicate and exchange data. In this project, the weather information is obtained from a public weather service API (wttr.in), which provides current weather data in JSON format. This API was chosen because it does not require authentication or an API key, making the application simple to develop and easy to run.

The frontend of the application was built using HTML and CSS. HTML was used to structure the webpage, including a title, search box, input field, and a section to display weather details. CSS was used to design the application with a modern and responsive user interface. The webpage features a blue gradient background, a centered white card, and neatly styled text and buttons. The layout automatically adjusts to different screen sizes, ensuring that the application works well on desktops, tablets, and mobile devices.

JavaScript was used to implement the application logic. When the user enters a city name and clicks the Search button, JavaScript sends an asynchronous request to the weather API using the Fetch API. The response is received in JSON format and parsed to extract useful information such as city name, temperature, weather condition, humidity, and wind speed. This data is then dynamically inserted into the webpage without requiring a page reload.

The project also includes error handling to improve reliability. If the user enters an invalid city name or if the API request fails, the application displays a meaningful error message instead of crashing. A default city (Hyderabad) is loaded automatically when the page opens, allowing users to see weather data immediately.

This project helped me understand important web development concepts such as API integration, asynchronous programming, JSON parsing, DOM manipulation, and responsive design. It also provided practical experience in using JavaScript’s async/await syntax and the Fetch API to retrieve real-time data from an external service.

Overall, this Weather App successfully fulfills the internship task requirements by creating a responsive webpage that dynamically fetches and displays data from a public API. The project demonstrates how APIs can be integrated into modern web applications to provide live and interactive content to users.**
